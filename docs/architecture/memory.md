# 持久记忆

项目规则从工作区规则文件加载。动态事实以追加 JSONL 保存，同一 ID 的最后一条记录决定当前状态；加载全部有效事实后再按查询和提示词预算选择，不在加载阶段截取前 32 条。

中文检索使用连续双字词项并支持单字查询；英文标识符先拆分驼峰再归一化。匹配分数使用查询词项覆盖率，避免长事实仅因正文较长而无法召回。不使用向量库。

提示词预算优先用于规则和用户置顶的记忆，普通事实再按相关性选择。规则基线按 kind=rule 筛选，不把文件中的前几条普通事实当作规则。includedCount 仅统计实际渲染的条目。

自动去重只合并清洗后正文完全一致且 kind、scope 相同的有效记忆。相似表述、否定句和不同事实保留各自 ID。达到 500 条有效记忆上限后允许合并已有条目，但拒绝新增条目。该去重不承担语义纠错职责。

宿主通过 `memoryRoot` 配置工作区私有目录，通过 `globalMemoryRoot` 配置当前本地资料的跨工作区目录。桌面使用 `<profileRoot>/memory` 存放全局记忆，各工作区 overlay 下的 `memory` 存放项目私有记忆。不同资料不共享全局目录。未配置全局目录的宿主不能写入 global 记忆；不能用修改 scope 字段把条目跨存储目录移动，应在目标范围创建并显式移除原条目。

全局和私有记忆都支持查询、编辑、置顶、移除与恢复；移除记录保留为 rejected 状态。全局目录参与快照指纹和运行时写入协调，事实文件仍以文件锁串行更新。规则缓存覆盖所有加载的 FLUXAGENT.md 路径及私有/全局记忆目录。

资料包 `components/memories/index.json` 使用 schemaVersion 2。items 中每项包含 `scope: global | workspace`、relativePath 和 content；workspace 项还必须带有效 workspaceId，global 项不带 workspaceId。导入将全局和工作区记忆分别写回新资料的对应目录，不接受旧组件格式或运行时迁移。

## 连续记忆内核（2026-10-18）

用户确认的产品约束：项目历史默认隔离，提供每项目的跨项目检索开关；后台使用当前对话模型，提供启停与用量限制。当前资料的通用个人偏好可成为全局记忆，项目事实与项目规则保持项目范围。不同本地资料不共享历史和记忆。

### 职责与数据

- `@fluxos/contracts/memoryTypes` 定义历史来源、分段证据、策略、摘要与维护状态，不依赖桌面。
- `@fluxos/conversations/conversations/conversationMemoryIndex` 从当前会话投影建立可重建的分段索引。原始事件日志仍是真实来源；索引包含消息身份、时间、正文摘要校验和与字符偏移。英文标识符拆分、中文双字词项、精确短语、词项覆盖和稀有度共同排序。按会话增量更新倒排表，正常重复搜索复用未变化的投影。超过 200 个会话继续分页，不截断语料。常见凭据表达沿用恢复导出的脱敏规则；偏移针对脱敏后的文本。
- `@fluxos/tools/memory/longTerm` 负责后台合成、策略、共享预算、租约、来源验证、时效、用户纠正与遗忘。宿主注入绑定当前资料和项目的 `MemoryHistorySource`，内核不自行猜测资料目录。
- `MemoryService` 统一项目规则、明确保存的记忆、派生记忆与按查询召回的原始片段。历史片段是数据，不能升级为当前指令或授权。规则与置顶记录优先，历史召回另有提示词预算，连续任务摘要只在继续/回顾类问题中作为线索注入。
- `AgentEngine.maintainMemory` 使用当前模型与现有协议适配器，关闭传输重试，记录 `purpose: memory` 的请求用量。无工具、无前台请求前缀，单次默认最多 24,000 字符输入与 2,000 输出 token；每轮集中处理一个会话，并按输出额度限制提炼条目数。摘要读取沿用三种现有协议的流解析器，支持网关在非流式请求下返回完整 SSE，拒绝中断的响应。
- 工作台只在资料和项目绑定完成后装配来源，空闲时调度；有前台工作则推迟，新任务、策略变化及关闭运行时会取消正在进行的整理。

全局目录中的 `synthesis.json` 保存当前资料的派生记录、会话摘要、分项目处理游标、遗忘来源、预算与短租约，以文件锁和原子替换提交。项目目录 `policy.json` 保存策略。`recall-index/` 是派生会话分片，不进入资料导出；导出合成状态时移除活动租约。模型结果通过来源校验后，记录、摘要与游标在同一次提交中更新；失败或中断不推进游标，已发起调用仍计入当天额度。模型输出不完整或无效时，下轮缩小来源批次，优先用更小输入恢复；同一日仍受共享调用上限约束。默认每日 20 次，计数在资料内共享，各项目配置阈值；日期按 UTC 重置。

模型仅引用本轮短编号（S1、S2 等），内核在提交时映射为真实消息身份，不接受本轮之外的来源。每条合成记忆附来源会话、消息、偏移、正文校验和与摘录。来源被编辑、移除、归档或不再可读时，派生记录标为 stale 并停止注入；摘要任一依据失效则不再使用。瞬时计划可携带到期时间，到期后失效，不把“计划发生”推断成“已经完成”。同一个语义键的新事实替换旧的自动记录，旧版本保留 superseded 状态。模型不能覆盖人工编辑或已拒绝的记录。

移除派生记忆会屏蔽其来源消息，阻止后台从同一原文重新提炼，也移除依赖该消息的摘要；这是消息粒度的排除，同条消息的其他内容也停止被历史召回。撤销可恢复该记忆的来源访问，但其他仍被拒绝记忆所屏蔽的来源继续排除。明确保存的人工条目与对话本身分别管理；没有消息身份的人工条目无法精确定位并屏蔽原始历史。

### 桌面交互

记忆设置提供历史参考、跨项目检索、后台整理和每日额度四项控制。摘要展示目标、决策、约束和未完成事项；依据通过渐进展开查看，可打开原对话。搜索同时覆盖已保存记忆及权限允许的对话片段，空结果提示更具体的名称或编号。后台错误保留为可见状态。

设计沿用现有主题：surface #ffffff、text #242421、muted #686864、faint #9b9b95、line #e7e7e3、accent #3f403d，暗色由公共变量接管；使用系统界面字体，标题/正文/说明明确分级，单列左对齐、正文不超过约 72ch。来源区用有意义的缩进和分隔，避免重复卡片与装饰，不新增切页入场动画。

### 验证与能力边界

自动测试覆盖长消息末尾细节、中文与标识符、200 条以上会话分页、项目范围与开关、来源修改和遮盖、损坏分片重建、取消、共享租约与额度、未知证据拒绝、人工纠正及到期。桌面设置另做开关保存、依据展开、主题与窄宽几何和截图检查。源码、测试夹具、安装包及真实模型效果分别报告。

词项索引不会保证同义改写下的全部召回；模型可多轮改写查询再读原文。来源校验保证引用实际存在且未改变，不证明模型提炼的每句话都与原文逻辑等价。摘要不是完整事实库；不能承诺“永远记住所有关键点”或已经达到 ChatGPT Pro 的实际效果。自动整理暂只消费用户与助手消息，工具结果可原文检索；尚未运行公开长期记忆基准或长时间实用评估。
